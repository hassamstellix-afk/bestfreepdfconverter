# best free pdf converter

Free, privacy-first PDF tools for [bestfreepdfconverter.com](https://bestfreepdfconverter.com). All processing runs in the browser — files are never uploaded.

## Stack

- Next.js 15 (App Router) + TypeScript + Tailwind CSS
- Client engines: pdf-lib, pdfjs-dist, docx, mammoth, SheetJS (xlsx), JSZip

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm start
```
